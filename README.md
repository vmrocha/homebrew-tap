# Homebrew Tap

Homebrew packages maintained by [Vinicius Rocha](https://github.com/vmrocha).

## Bible CLI

Install the offline-first command-line Bible reader:

```console
brew install vmrocha/tap/bible-cli
```

Then verify the installation:

```console
bible version
bible read "John 3:16"
```

The formula builds from the tagged source release and installs shell
completions for Bash, Zsh, and Fish.

## Documentation

See the [Bible CLI installation guide](https://vmrocha.github.io/bible-cli/guide/installation)
and [Homebrew documentation](https://docs.brew.sh/).
